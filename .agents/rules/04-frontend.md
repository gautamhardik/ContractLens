# Rule 04: Frontend Conventions

1. **Current Status**: No frontend application or UI framework has been established yet in the repository.
2. **Framework Alignment**: When frontend tasks begin, confirm technology choices in `DECISIONS.md` before generating code.
3. **Vanilla & Component Discipline**: Favor clean, modular component structures with semantic HTML and maintainable styling as decisions dictate.
4. **No Premature Build Chains**: Do not introduce complex build pipelines, bundlers, or CSS frameworks until explicitly decided in task milestones.
